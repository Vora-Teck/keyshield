Why KeyShield?

Built for applications where input security matters — banking, wallets, authentication, and any form that handles secrets.

🔒

Blocks native keyboard

Forces inputmode="none", keeps fields readonly while active, and temporarily rewrites type="number" / tel so the OS never shows its keyboard.

📱

Native-like behaviour

Bottom-fixed layout, content spacer that pushes the page up, safe-area support, Back-button closes the keyboard first, Enter submits forms.

🌐

Multi-language

English (US/UK) and Arabic (RTL) built-in. Language switch key lets users cycle layouts. Easy to add more.

🎨

Themes & animation

Dark, Light and Fintech themes. Optional slide-in and key-press animations. Size breakpoints control where it activates.

⚙️

Full lifecycle API

config(), update(), init(), stop(), clear(). Singleton guarantees only one instance runs.

📦

Drop-in

Pure ES module or global script tag. No build step, no dependencies. Works with any framework or plain HTML.

Installation & Usage

Choose the integration style that fits your project.

ES Module Script tag (global) Quick start

1. ES Module (recommended)

Import the class and create a single instance.

import { Keyboard } from "./keyshield.js";
// or the minified module:
// import { Keyboard } from "./keyshield.min.js";

const keyboard = new Keyboard({
  class: "secure-input",          // only elements with this class
  types: ["text", "password", "number"],
  theme: "fintech",
  size: "all",                    // xs | sm | md | lg | xl | all
  animation: true,
  lang: ["en-us", "ar"],
  preventNative: true,
  vibrate: true
});

keyboard.init();                  // start listening

You can also configure after construction:

const keyboard = new Keyboard();
keyboard.config({ theme: "dark", class: "secure-input" });
keyboard.init();

// later
keyboard.update({ theme: "light", animation: false });
keyboard.stop();   // restore native keyboard
keyboard.clear();  // stop + wipe config

2. Script tag / Global build

For projects that prefer a classic <script> include (no bundler, no type="module").

<!-- Place before your own scripts -->
<script src="./keyshield.global.js"></script>
<script>
  // KeyShield (and Keyboard) are now on window
  const keyboard = new KeyShield({
    class: "secure-input",
    theme: "dark",
    animation: true,
    lang: ["en-us", "en-uk", "ar"]
  });
  keyboard.init();
</script>

Alias available: window.Keyboard === window.KeyShield.

Minimal HTML example

<!DOCTYPE html>
<html>
<head>
  <meta name="viewport" content="width=device-width, initial-scale=1">
</head>
<body>
  <input type="password" class="secure-input" placeholder="Password">
  <input type="number"  class="secure-input" placeholder="PIN">

  <script type="module">
    import { Keyboard } from "./keyshield.js";
    new Keyboard({ class: "secure-input", theme: "fintech" }).init();
  </script>
</body>
</html>

API Reference

Constructor & configuration options

OptionTypeDefaultDescription
class string | null null CSS class that marks inputs the keyboard should attach to. When set, both class and type must match.
types string[] ["text","number","url","email","password","tel","search"] Input types the keyboard applies to.
theme string "dark" "dark" | "light" | "fintech"
size string "all" Max viewport width the keyboard activates on: xs (≤480), sm, md, lg, xl, all.
animation boolean false Slide-in / slide-out and key-press scale animation.
lang string[] ["en-us"] Available layouts. Built-in: en-us, en-uk, ar. Cycle with the 🌐 key.
preventNative boolean true Aggressively block the OS keyboard.
vibrate boolean true Short haptic feedback on key press (where supported).
maxLengthRespect boolean true Honour the input’s maxlength attribute.

Methods

MethodDescription
config(options) Set / replace configuration. Chainable. Does not start the keyboard.
update(options) Merge new options. If already initialized, restarts listeners and UI automatically.
init() Inject styles & DOM, attach event listeners. Call once (or after stop).
stop() Remove listeners and keyboard UI. Native keyboard is restored.
clear() stop() + reset all configuration to defaults.

Behaviour notes

  • Only one instance is allowed (singleton). Constructing again returns the existing instance.
  • Hardware / software Back button closes the keyboard first (history state trick).
  • Escape key also dismisses the keyboard.
  • Enter on single-line inputs submits the parent form when present.
  • Number / tel fields automatically open the numeric layout.

Extending KeyShield

The library is intentionally self-contained so you can fork or patch it easily.

Adding a new language / layout

Open keyshield.js and extend the LAYOUTS object:

const LAYOUTS = {
  // … existing …
  "fr": {
    name: "Français",
    alpha: [
      ["a","z","e","r","t","y","u","i","o","p"],
      ["q","s","d","f","g","h","j","k","l","m"],
      ["⇧","w","x","c","v","b","n","'","⌫"],
      ["123","🌐"," ",".","↵"]
    ],
    number: [ /* same structure as en-us */ ],
    symbols: [ /* … */ ]
  }
};

Then pass lang: ["en-us", "fr"] in the config. The 🌐 key will cycle through the list.

Adding a custom theme

Extend the THEMES object with the same keys:

const THEMES = {
  // …
  midnight: {
    bg: "#0a0a12",
    keyBg: "#161622",
    keyBgActive: "#22223a",
    keyText: "#e0e0ff",
    keyBorder: "#2a2a44",
    specialBg: "#1c1c30",
    accent: "#7c3aed",
    shadow: "0 -4px 24px rgba(0,0,0,0.55)"
  }
};

Use it with theme: "midnight".

Hooking into key events

The library dispatches standard input and change events on the target element after every key action. Listen to those as you normally would:

document.querySelector(".secure-input")
  .addEventListener("input", (e) => {
    console.log("value now:", e.target.value);
  });

Framework usage (React / Vue / Svelte…)

Create the instance once (e.g. in a layout or plugin) and call init() after the DOM is ready. Because it listens at the document level with capture, it works with dynamically rendered inputs.

// React example (run once)
useEffect(() => {
  const kb = new Keyboard({ class: "secure-input", theme: "fintech" });
  kb.init();
  return () => kb.stop();
}, []);
